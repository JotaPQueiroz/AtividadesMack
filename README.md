📚 Atividades da Faculdade

Este repositório foi criado para armazenar e organizar as atividades, exercícios, projetos e trabalhos desenvolvidos durante a graduação.

🎓 Objetivo

O objetivo deste repositório é manter as atividades acadêmicas organizadas, facilitando o acompanhamento da evolução dos estudos e o acesso aos conteúdos desenvolvidos em cada disciplina.

📂 Organização

As atividades estão organizadas de acordo com as disciplinas e conteúdos estudados.
